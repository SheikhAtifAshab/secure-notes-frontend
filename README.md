# Secure Notes - Frontend

Plain HTML/JS (no build step, no framework). Talks to the backend REST API.

1. Edit `config.js` and set `window.API_BASE` to the backend URL.
2. Run locally: `npx serve .` (or open `index.html` through any static server).
3. Deploy: Vercel or Netlify, framework "Other", no build command, output directory = repo root.
